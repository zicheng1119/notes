这是一篇**可随时回看复制**的模板集。每个模块就是一个 callout，写法是 `> [!类型] 标题`，正文每行前面加 `> `。框内可以正常写 LaTeX：行内 `$...$`、独立公式 `$$...$$`。

> [!tip] 折叠技巧
> 在类型后加 `-` 默认折叠（如 `> [!proof]-`），加 `+` 可折叠但默认展开。很适合把冗长的证明收起来。

## 可复制模板

**定义**
```markdown
> [!definition] 名称
> 这里写定义内容，可含 $公式$。
```

**定理**
```markdown
> [!theorem] 名称
> 定理陈述。
```

**引理 / 推论 / 命题**
```markdown
> [!lemma] 引理 X
> ...

> [!corollary] 推论 X
> ...

> [!proposition] 命题 X
> ...
```

**证明（默认折叠）**
```markdown
> [!proof]-
> 证明过程……$\blacksquare$
```

**例 / 注**
```markdown
> [!example] 例 1
> ...

> [!remark] 注
> ...
```

## 实战示例（实时渲染）

> [!definition] 收敛
> 数列 $\{a_n\}$ 收敛于 $L$，若 $\forall \varepsilon > 0,\ \exists N,\ \forall n > N:\ |a_n - L| < \varepsilon$。

> [!theorem] 单调有界定理
> 单调递增且有上界的实数列必收敛。

> [!proof]-
> 设 $\{a_n\}$ 单调递增且有上界，由确界原理存在上确界 $L = \sup_n a_n$。对任意 $\varepsilon > 0$，由上确界定义存在 $N$ 使 $a_N > L - \varepsilon$；又因单调，$\forall n > N$ 有
> $$L - \varepsilon < a_N \le a_n \le L < L + \varepsilon,$$
> 即 $|a_n - L| < \varepsilon$，故 $a_n \to L$。$\blacksquare$

> [!remark] 注
> 把上确界换成下确界，可得「单调递减有下界必收敛」的对偶版本。
