这是一篇**可随时回看的参考文章**。每一节都给出「什么时候用 → 怎么写 → 实际效果」。需要时直接复制对应代码片段到任意笔记即可。

> [!tip] 两个通用规则
> 1. **本地文件**（图片 / 视频 / PDF / 音频 / GIF）要先放进 `content/` 文件夹里（在 Obsidian 里直接拖进来也行），再用相对路径 `./文件名` 或 Obsidian 双链 `![[文件名]]` 引用。
> 2. **Bilibili 和 PDF** 靠原始 HTML 嵌入，`<iframe>` 必须用 `<div class="embed">` 包住，才会是 16:9 圆角自适应；裸 `<iframe>` 不会自适应。

## 图片

最常用。支持 Markdown 写法和 Obsidian 双链两种：

```markdown
![图片说明](./photo.png)
![[photo.png]]
```

图片现在自带圆角，鼠标悬停会有放大光标和轻微缩放。下面是一张实时示例图：

![一张示例图片](https://images.unsplash.com/photo-1517336714731-489689fd1ca8?w=800)

## 本地视频

放在仓库里的 `.mp4` 文件，直接播放：

```html
<video controls src="./video.mp4"></video>
```

也可以用双链 `![[video.mp4]]`。

## YouTube

原生支持，直接把链接当图片贴上即可，会自动变成播放器：

```markdown
![](https://www.youtube.com/watch?v=dQw4w9WgXcQ)
```

## Bilibili

复制视频的 BV 号，替换下面的 `bvid`：

```html
<div class="embed"><iframe src="https://player.bilibili.com/player.html?bvid=BV1xx411c7mD&autoplay=0" allowfullscreen></iframe></div>
```

实际效果（16:9 圆角响应式）：

<div class="embed"><iframe src="https://player.bilibili.com/player.html?bvid=BV1xx411c7mD&autoplay=0" allowfullscreen></iframe></div>

## PDF

把 `.pdf` 放进 `content/`，内嵌翻页阅读（`.embed pdf` 是更高的 3:4 比例）：

```html
<div class="embed pdf"><iframe src="./slides.pdf"></iframe></div>
```

## 音频

```html
<audio controls src="./audio.mp3"></audio>
```

## 动画

- **GIF**：当图片插入即可 —— `![](./anim.gif)`
- **手绘动画 / 可交互图**：用 Excalidraw（`.excalidraw` 文件），插件已开启，支持交互与暗色自适应
